# Foidy Hub Apps

Репозиторий приложений **Foidy Technologies**, предназначенных для установки и обновления исключительно через [Foidy Hub](https://github.com/foidy/foidy-hub)

> [!IMPORTANT]
> Этот репозиторий является частью внутренней инфраструктуры Foidy Technologies.
>  
> Приложения загружаются, устанавливаются и обновляются автоматически через [Foidy Hub](https://github.com/foidy/foidy-hub).  
> Ручное использование или запуск содержимого репозитория не поддерживается и не рекомендуется.

---

## Назначение

**Foidy Hub Apps** служит единым источником распространения приложений, обеспечивая:
- контролируемые обновления  
- целостность версий  
- стабильность и предсказуемость пользовательского опыта  

Репозиторий не предназначен для прямого взаимодействия с пользователем.

---

## Принципы работы приложений

Каждое приложение в составе репозитория:

- Работает полностью локально  
- Поддерживает автоматическое обновление через [Foidy Hub](https://github.com/foidy/foidy-hub)  
- Не использует серверы и телеметрию  
- Соответствует стандартам экосистемы Foidy Technologies
